Guide: Creating a JupyterLite Site and Linking It from Canvas

This guide documents the process we followed to publish Jupyter notebooks via GitHub Pages and make them accessible to students through Canvas.

Step 1: Create a GitHub Repository

  1. Log in to GitHub.
  2. Click New Repository.
  3. Give it a name, for example:

MACO-Sets-01

  1. Create the repository.

Step 2: Create a JupyterLite Site

Instead of starting from scratch, use the JupyterLite template.

  1. Visit the JupyterLite demo template repository.
  2. Click Use this template.
  3. Create a new repository from the template.

This automatically includes:

  • JupyterLite
  • GitHub Actions workflows
  • GitHub Pages configuration

Step 3: Upload Notebooks

  1. Open the repository.
  2. Go to the content folder.
  3. Click Add file → Upload files.
  4. Upload your notebooks.

Example:

content/

├── Week01.ipynb

├── Week02.ipynb

└── Exercises.ipynb

  1. Commit the changes.

Step 4: Configure GitHub Pages

Open:

Settings → Pages

Under Build and deployment:

Source = GitHub Actions

Do NOT use:

Deploy from a Branch

for the JupyterLite template.

Step 5: Enable GitHub Actions Permissions

Open:

Settings → Actions → General

Scroll to:

Workflow permissions

Select:

Read and write permissions

Click:

Save

Step 6: Allow GitHub to Build

Open:

Actions

You should see a workflow called something similar to:

Build and Deploy

Wait until you see:

✅ Build

✅ Deploy

If necessary:

Re-run jobs → Re-run all jobs

Step 7: Confirm the Site is Live

Open:

Settings → Pages

You should see:

Your site is live at:

https://YOURUSERNAME.github.io/REPOSITORY-NAME/

Example:

https://dbarnett404.github.io/MACO-Sets-01/

Step 8: Launch JupyterLite

Open:

https://YOURUSERNAME.github.io/REPOSITORY-NAME/lab/

Example:

https://dbarnett404.github.io/MACO-Sets-01/lab/

A JupyterLab-style interface should appear.

The notebooks should be visible in the left-hand file browser.

Step 9: Remove Example Notebooks (Optional)

The template includes example files such as:

javascript.ipynb

p5.ipynb

python.ipynb

To delete:

  1. Open the file.
  2. Click the ... menu.
  3. Select Delete file.
  4. Commit the change.

Do not delete:

pyodide/

as it contains components required for Python support.

Step 10: Get a Direct Notebook Link

Open a notebook in JupyterLite.

For example:

Week01.ipynb

Copy the URL from the browser.

It will look something like:

https://YOURUSERNAME.github.io/REPOSITORY-NAME/lab/index.html?path=Week01.ipynb

``

This launches directly into the notebook.

Step 11: Add to Canvas

In Canvas:

Modules → +

Choose:

External URL

Paste either:

Entire JupyterLite Site

https://YOURUSERNAME.github.io/REPOSITORY-NAME/lab/

``

or

Direct Notebook Link

https://YOURUSERNAME.github.io/REPOSITORY-NAME/lab/index.html?path=Week01.ipynb

``

Tick:

Load in a new tab

Click:

Add Item

Common Error

GitHub 404 Page

If students see:

404 File not found

check that the repository name in the URL exactly matches the actual repository.

For example:

❌

https://dbarnett404.github.io/MACO-Sets/

``

✅

https://dbarnett404.github.io/MACO-Sets-01/

The repository name and URL must match exactly.

Recommended Structure for Teaching

content/

├── Week01 Introduction.ipynb

├── Week01 Exercises.ipynb

├── Week02 Introduction.ipynb

├── Week02 Exercises.ipynb

└── README.md

Then create one Canvas link per notebook so students go directly to the activity they need to complete.

This approach requires no server, no JupyterHub, and students can run Python entirely within their browser.
